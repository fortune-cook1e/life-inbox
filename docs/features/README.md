# Feature Briefs

This directory contains temporary briefs for large features that span multiple
sessions, applications, or independently verifiable slices.

Use the Feature Brief structure in [`../agent-workflow.md`](../agent-workflow.md).
Frontend, backend, and Agent work that serves one user-visible capability should
share one brief. Do not create a brief for a small change that can be clarified
and completed safely in one session.

A brief may reference canonical documents but must not redefine them. When the
feature is complete, move durable behavior and decisions to their authoritative
owners; keep current progress in `docs/HANDOFF.md`, not in the brief.

There are no active Feature Briefs yet.
